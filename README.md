# Runner Game 🏃‍♂️💨

A simple 2D browser game built with **HTML5 Canvas**, **JavaScript**, **Phaser.js** (game engine), and basic **game loop mechanics**.  
The goal is to collect coins while avoiding the enemy.

## 🚀 Features

- Player movement with **keyboard, touch buttons, joystick, and gyroscope support**
- **Enemy AI** that chases the player
- **Coins system** with scoring
- **Countdown timer** before game starts
- **Background music and sound effects**
- Mobile responsive controls

## 🎮 How to Play

- Use Arrow Keys (⬆️⬇️⬅️➡️) or on-screen joystick on mobile.
- Collect coins to increase your score.
- Avoid the enemy, or it's **Game Over**.

## 🛠️ Tech Stack

- **HTML5 Canvas**
- **JavaScript (Vanilla JS)**
- **CSS3**
- **Phaser.js (for inspiration, not in final build)**
